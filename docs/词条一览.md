# 词条一览（给玩家 / 朋友看的版本）

> 这是 **lore_enchant 词条插件** 的全部内容：共 **23 个词条**（武器 14 + 护甲 9）。
> 物品的 **说明文字（lore）** 里写「词条名 + 等级」就会生效，例如 `雷神III`、`死亡领域5`。

---

## 一句话说明

- **武器词条**：你**打人时**按概率触发
- **护甲词条**：你**挨打时**按概率让**打你的人**中招
- 等级越高 → **触发概率越高**（部分词条强度也随等级提高）
- 概率满级都是 **100%**

## 强度规则（状态类词条）

**词条等级 = 药水等级 − 1**，也就是：

| 词条等级 | I | II | III | … | X |
| --- | --- | --- | --- | --- | --- |
| 游戏内显示 | 效果 II | 效果 III | 效果 IV | … | 效果 XI |

所以 **10 级淬毒 = 中毒 XI**，**10 级飞升 = 漂浮 XI**（飞升起飞非常快，注意摔伤）。

例外：**饥荒 / 荒芜领域** 固定 255 级，不随等级变。

## 怎么给装备加词条（管理员）

**方式一：命令**（OP，手持物品执行）

```
/le 雷神 10          → 这把武器写「雷神 X」
/le 死亡领域 5        → 这件护甲写「死亡领域 V」
/le XiYingKill 11    → 100% 秒杀
```

**方式二：GUI**（OP）

```
/legui
   → 武器附魔 / 护甲附魔 / 一键清除词条
   → 选词条 → 拖滑块选等级 → 提交
```

**方式三：一键清除**

```
/legui → 一键清除词条      （有确认页）
/le clear                  （命令版，直接清）
```

只会删本插件的词条行，**其它 lore 原样保留**。

## 注意事项（介绍时可以说清楚）

1. **亡灵免疫中毒**：僵尸 / 骷髅 / 凋灵 不吃「淬毒」，但吃「死亡（凋零）」。
2. **爆破是真实爆炸**：不破坏方块，但会伤害并击退范围内**所有**生物——**站太近自己也会被炸**。
3. **终焉混沌很凶**：挨一下同时上失明+黑暗+缓慢+漂浮，PvP 里基本等于致残，建议只给高价值装备。
4. **斩绝要残血**：目标血量 > 30% 时，就算 100% 概率也**不会**斩杀。
5. **狂骨回血固定 3 点**：升级只提高触发概率，不会回得更多（也不会超血量上限）。
6. **护甲词条只在护甲栏生效**（背包里的不算），每件装备**独立判定**。
